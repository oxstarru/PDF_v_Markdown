# PDF в Markdown

## Краткое описание

Утилита превращает PDF в аккуратную заметку для базы знаний: текст становится Markdown с заголовками, списками и таблицами, а картинки из документа — фотографии, схемы, формулы, диаграммы — сохраняются отдельными файлами и подставляются в текст ссылками. Перед сохранением можно посмотреть все найденные картинки и оставить только нужные. Всё происходит прямо в браузере: файл никуда не уходит, интернет не нужен.

## Как работает

- **Где работает:** в любом современном браузере. Открывается двойным щелчком по файлу, установка не нужна.
- **Что делать:** перетащите PDF в рамку или нажмите «Выбрать файл». Через несколько секунд появится готовый Markdown. Дальше — «Копировать текст», «Скачать .md» или «Скачать архив», если хотите забрать картинки вместе с текстом.
- **Картинки:** утилита находит их сама. Кнопка «Показать картинки» открывает галерею с превью — снимите галочку с тех, что не нужны, и они пропадут и из архива, и из текста. Одна и та же картинка на многих страницах (логотип в шапке) отдаётся один раз; мелкий декор меньше 50 пикселей пропускается.
- **Галочка «Приложить страницы картинками»** — про другое: она сохраняет каждую страницу целиком отдельным PNG. Нужна, когда хочется свериться с оригиналом или вёрстка сложная.

## Нюансы

- Утилита работает с PDF, у которых есть текстовый слой: документы из Word, презентации, силлабусы, статьи. Со сканами и страницами-картинками офлайн ничего не сделать — такие лучше показать ИИ в чате, он прочитает их глазами.
- Картинки достаются и из презентаций, выгруженных из Google Slides и Canva, — там они спрятаны глубже обычного, но утилита их находит.
- Простые таблицы собираются в Markdown-таблицу. Сложные, с объединёнными ячейками, и многоколоночная вёрстка передаются упрощённо.
- Схемы, нарисованные линиями и фигурами (не вставленные картинкой), отдельным файлом не сохраняются — для них пригодится галочка «приложить страницы картинками».
- Большие документы обрабатываются заметное время: каждая страница разбирается по-настоящему.

## Приватность

Данные остаются только на вашем компьютере. Утилита не обращается в интернет: шрифты системные, все библиотеки лежат внутри самого файла. Можно работать без сети.
